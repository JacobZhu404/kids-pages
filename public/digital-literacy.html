turtle 画笔、重复与递归

turtle 是 Python 自带的绘图模块。先把海龟想成拿着画笔的小车：它有当前位置、朝向和落下或抬起的画笔。

常用动作

  • t.forward(80)：向前画80步
  • t.left(90) / t.right(90)：转向
  • t.penup() / t.pendown()：移动时不画 / 开始画
  • t.goto(x, y)：移动到坐标
  • t.color("green")：设置颜色

while 控制重复

# 重复画正方形的四条边
for i in range(4):
    t.forward(80)  # draw one side
    t.left(90)  # turn before drawing the next side

# while 也可以按条件重复
count = 0
while count < 4:
    t.forward(40)  # draw one side
    t.left(90)  # turn for the next side
    count = count + 1  # update the counter so while eventually stops
递归的三步：①检查停止条件；②画当前这一段；③调用自己画更小的部分。比如 if length < 10: return 表示枝条够短就停止；每次把长度缩小，递归才会走向出口。函数走到 return 后，会回到刚才调用它的位置，继续执行后面的语句。

print() 可以帮助观察递归：打印 depth 或 length，运行时就能看到每一层如何变小。复杂图形可用 t.tracer(False) 暂停逐笔刷新，画完后用 t.update() 一次显示。

看一段把 turtle 和递归连起来的代码
import turtle as t  # 导入内置绘图模块，并简称为 t

def draw_branch(length, depth):
    print("这一层：", depth, "枝长：", length)  # 打印递归过程
    if depth == 0 or length < 8:
        return  # 到达停止条件，回到上一层调用

    t.forward(length)  # 画当前枝条
    t.left(25)
    draw_branch(length * 0.7, depth - 1)  # 画左侧小枝
    t.right(50)
    draw_branch(length * 0.7, depth - 1)  # 画右侧小枝
    t.left(25)
    t.backward(length)  # 回到本层起点

draw_branch(100, 5)

递归程序里最重要的两句话

def draw(length): # Stop when the branch becomes too short if length < 10: return # 停止条件：太短就不画 draw(length * 0.7) # 递归画更短的左枝 draw(length * 0.7) # 递归画更短的右枝

停止条件像“安全刹车”。如果没有停止条件，函数会一直叫自己，程序就停不下来。

样例的读法：draw(l) 表示画边长为 l 的结构；每次递归时长度变成原来的 3/5 或 4/5。当 l ≤ 10，条件 if l > 10 不成立，递归自然停下。

真正的样例还要用 turtle 转向、画正方形、回到起点再画另一支。先理解“长度越来越小 + 递归会停”，再逐句照着任务要求补图形细节。

turtle 动作词小抄

t.fd(长度)：向前走
t.bk(长度)：向后退

t.lt(角度)：向左转
t.rt(角度)：向右转

t.pu()：抬起画笔，移动不留线
t.pd()：落下画笔，开始画

t.goto(x, y)：移动到坐标
t.color(...)：改画笔颜色

样例用 t.tracer(False) 暂停逐笔刷新，最后 t.update() 一次显示，能加快复杂图形的绘制。

pandas：表格、行列和计算

pandas 是处理表格数据的工具。DataFrame 可以理解成一张表：每一列有列名，每一行是一条记录。下面用小表演示常用操作。

# 字典中的每个列表代表一列；相同位置的数据组成一行
scores = pd.DataFrame({
    "姓名": ["小明", "小红", "小刚"],
    "语文": [80, 92, 75],
    "数学": [90, 88, 85]
})

# 用列名访问整列
print(scores["数学"])

# .loc[行标签, 列名] 访问指定行和列；这里行标签0是第一行
print(scores.loc[0, "姓名"])

# 用切片选取多行、多列；: 表示该方向取全部
print(scores.loc[0:1, ["姓名", "语文"]])

# 两列可以逐行相加，结果保存为新列
scores["总分"] = scores["语文"] + scores["数学"]

# groupby 按班级分组；sum 对每组的数值列求和
scores["班级"] = ["一班", "一班", "二班"]
print(scores.groupby("班级")["总分"].sum())

观察正方形、直角三角形和两个较小正方形的递归关系。

把大正方形的边长当作 5，两个小正方形的边长就是 3 和 4：3² + 4² = 5²。因此分支长度分别是原来的 0.6 和 0.8。动画中的虚线表示三角形的两条直角边。

import turtle as t
import random
import math

def draw(x, y, size, angle, depth):
    # 停止条件：层数用完就返回
    if depth == 0:
        return
    a = math.radians(angle)  # convert degrees to radians for trig functions
    ux, uy = math.cos(a), math.sin(a)  # direction of the square base
    vx, vy = -uy, ux  # perpendicular direction for its sides
    # 正方形四个顶点
    A = (x, y)  # lower-left corner
    B = (x + size * ux, y + size * uy)  # lower-right corner
    D = (x + size * vx, y + size * vy)  # upper-left corner
    C = (B[0] + size * vx, B[1] + size * vy)  # upper-right corner
    t.pu()
    t.goto(A)
    t.pd()
    t.color(random.random(), random.random(), random.random())
    for point in [B, C, D, A]:  # visit corners and close the square
        t.goto(point)
    # 直角三角形的两条直角边：0.6s 与 0.8s
    P = (D[0] + .36 * size * ux + .48 * size * vx,
         D[1] + .36 * size * uy + .48 * size * vy)
    draw(D[0], D[1], size * .6,
         angle + math.degrees(math.atan2(4, 3)), depth - 1)
    draw(P[0], P[1], size * .8,
         angle - math.degrees(math.atan2(3, 4)), depth - 1)

t.setup(900, 700)
t.tracer(False)
t.ht()
draw(-60, -250, 120, 0, 7)
t.update()
t.done()
