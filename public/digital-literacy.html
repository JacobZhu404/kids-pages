turtle 画笔、重复与递归

turtle 是 Python 自带的绘图模块。先把海龟想成拿着画笔的小车：它有当前位置、朝向和落下或抬起的画笔。

常用动作

  • t.forward(80)：向前画80步
  • t.left(90) / t.right(90)：转向
  • t.penup() / t.pendown()：移动时不画 / 开始画
  • t.goto(x, y)：移动到坐标
  • t.color("green")：设置颜色

while 控制重复

# 重复画正方形的四条边
for i in range(4):
    t.forward(80)  # 画正方形的一条边。
    t.left(90)  # 转向后再画下一条边。

# while 也可以按条件重复
count = 0
while count < 4:
    t.forward(40)  # 画正方形的一条边。
    t.left(90)  # 转向，准备画下一条边。
    count = count + 1  # 更新计数，保证while最终能停止。
递归的三步：①检查停止条件；②画当前这一段；③调用自己画更小的部分。比如 if length < 10: return 表示枝条够短就停止；每次把长度缩小，递归才会走向出口。函数走到 return 后，会回到刚才调用它的位置，继续执行后面的语句。

print() 可以帮助观察递归：打印 depth 或 length，运行时就能看到每一层如何变小。复杂图形可用 t.tracer(False) 暂停逐笔刷新，画完后用 t.update() 一次显示。

看一段把 turtle 和递归连起来的代码
import turtle as t  # 导入内置绘图模块，并简称为 t

def draw_branch(length, depth):
    print("这一层：", depth, "枝长：", length)  # 打印递归过程
    if depth == 0 or length < 8:
        return  # 到达停止条件，回到上一层调用

    t.forward(length)  # 画当前枝条
    t.left(25)
    draw_branch(length * 0.7, depth - 1)  # 画左侧小枝
    t.right(50)
    draw_branch(length * 0.7, depth - 1)  # 画右侧小枝
    t.left(25)
    t.backward(length)  # 回到本层起点

draw_branch(100, 5)

递归程序里最重要的两句话

def draw(length): # 枝条太短时停止递归。 if length < 10: return # 停止条件：太短就不画 draw(length * 0.7) # 递归画更短的左枝 draw(length * 0.7) # 递归画更短的右枝

停止条件像“安全刹车”。如果没有停止条件，函数会一直叫自己，程序就停不下来。

样例的读法：draw(l) 表示画边长为 l 的结构；每次递归时长度变成原来的 3/5 或 4/5。当 l ≤ 10，条件 if l > 10 不成立，递归自然停下。

真正的样例还要用 turtle 转向、画正方形、回到起点再画另一支。先理解“长度越来越小 + 递归会停”，再逐句照着任务要求补图形细节。

turtle 动作词小抄

t.fd(长度)：向前走
t.bk(长度)：向后退

t.lt(角度)：向左转
t.rt(角度)：向右转

t.pu()：抬起画笔，移动不留线
t.pd()：落下画笔，开始画

t.goto(x, y)：移动到坐标
t.color(...)：改画笔颜色

样例用 t.tracer(False) 暂停逐笔刷新，最后 t.update() 一次显示，能加快复杂图形的绘制。

DataFrame 可以看成一张表：列有列名，行有行标签。用列名取列，用 .loc 按行标签和列名定位。

import pandas as pd

# 字典中的每个列表代表一列；相同位置的数据组成一行
scores = pd.DataFrame({
    "班级": ["一班", "一班", "二班"],
    "姓名": ["小明", "小红", "小刚"],
    "语文": [80, 92, 75],
    "数学": [90, 88, 85]
})

# 用列名访问整列
print(scores["数学"])

# .loc[行标签, 列名] 访问指定单元格；默认行标签从0开始
print(scores.loc[0, "姓名"])

# 选取标签0到1的行（包含1），以及指定的两列
print(scores.loc[0:1, ["姓名", "语文"]])

# 两列逐行相加，结果存入新列“总分”
scores["总分"] = scores["语文"] + scores["数学"]

# groupby按班级分组；sum计算每组总分之和
print(scores.groupby("班级")["总分"].sum())

这几个写法的意思：表["列名"]取一列；表.loc[行标签, "列名"]取指定单元格；新列 = 列A + 列B逐行计算；groupby(...).sum()分组后求和。CSV 读入后得到的 df 也是 DataFrame。

把大正方形的边长当作 5，两个小正方形的边长就是 3 和 4：3² + 4² = 5²。因此分支长度分别是原来的 0.6 和 0.8。动画中的虚线表示三角形的两条直角边。

完整画树代码（教学改编）

# turtle用可移动的画笔绘图。
import turtle as t
# random随机选择树枝颜色。
import random
# math用于角度换算和三角函数计算。
import math

# 先画一个正方形，再递归画上方的小正方形。
def draw(x, y, size, angle, depth):
    # 停止条件：层数用完就返回。
    if depth == 0:
        return
    # 将角度换成sin和cos函数使用的弧度。
    a = math.radians(angle)
    # 底边的单位方向向量。
    ux, uy = math.cos(a), math.sin(a)
    # 与底边垂直的边方向向量。
    vx, vy = -uy, ux
    # 正方形四个顶点
    A = (x, y)
    B = (x + size * ux, y + size * uy)
    D = (x + size * vx, y + size * vy)
    C = (B[0] + size * vx, B[1] + size * vy)
    # 抬笔移动到角点，不画连接线。
    t.pu()
    t.goto(A)
    # 落笔，开始绘制正方形。
    t.pd()
    # 随机选择红、绿、蓝三个颜色分量。
    t.color(random.random(), random.random(), random.random())
    # 依次经过四个顶点，回到起点闭合正方形。
    for point in [B, C, D, A]:
        t.goto(point)
    # 直角三角形的两条直角边：0.6s 与 0.8s
    # 根据3、4、5直角三角形的比例计算屋顶顶点。
    P = (D[0] + .36 * size * ux + .48 * size * vx,
         D[1] + .36 * size * uy + .48 * size * vy)
    # 左侧子正方形边长为父正方形的3/5。
    draw(D[0], D[1], size * .6,
         angle + math.degrees(math.atan2(4, 3)), depth - 1)
    # 右侧子正方形边长为父正方形的4/5。
    draw(P[0], P[1], size * .8,
         angle - math.degrees(math.atan2(3, 4)), depth - 1)

# 设置合适大小的绘图窗口。
t.setup(900, 700)
# 暂停逐笔刷新，加快绘图速度。
t.tracer(False)
# 隐藏海龟光标。
t.ht()
draw(-60, -250, 120, 0, 7)
# 图形画完后刷新屏幕。
t.update()
# 保持绘图窗口打开，直到手动关闭。
t.done()

想让递归停止，下面哪种写法最关键？

正确！停止条件是递归的刹车；同时每次要朝停止条件前进。

闯关 B｜pandas 找最大值

想找“房龄(年)”这一列的最大值，该写哪句？

对啦！先选列，再用 max() 求最大值。平均数则用 mean()。

闯关 C｜特征工程

面积 100㎡、房价 400 万元，每平米价格是多少？

万元/㎡
答案是 4 万元/㎡：400 ÷ 100 = 4。记住先确认单位，再做除法。

这三项都要检查。题目若指定图表类型，就按要求作图。

  • 赛前在 Python 3.8 + IDLE 里亲自运行练习代码。
  • 确认电脑电量充足；规则说明现场无电源、无网络。
  • 比赛不能联网；不带 U 盘、计算器、对讲机等规则禁止的工具。

⏱️ 做题顺序

  1. 先读完题目，圈出每个小要求。
  2. 先完成自己最熟的部分，保证程序能运行。
  3. 再补统计、特征和图表细节。
  4. 最后留时间检查输出与保存文件。
