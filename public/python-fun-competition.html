模块一：Python 写法与游戏指令

目标：看懂代码块，能把“向前走、转弯、遇到目标就行动”翻译成程序。

① 快速认 Python 语法

# 赋值：把数值放进变量 steps = 3 # if 后面写条件，冒号后缩进表示要执行的内容 if steps == 3: print("走三步") # repeat 是比赛平台提供的循环指令示例 repeat(steps): move(1)

记住：= 是赋值，== 是比较；冒号后面的代码要缩进。Python 用缩进表示“这些指令属于 if 或循环”。

② 先读目标，再想步骤

  1. 角色现在在哪、朝哪个方向？
  2. 目标在前后左右哪个位置？中间有障碍吗？
  3. 重复动作能不能用 repeat()？
  4. 题目有没有要求使用某个知识点或限制代码行数？

运行后如果走错，先检查方向和步数，再检查条件是否写反。

规则附件中的闯关指令

指令/写法按附件的解释练习时检查
move(n)向前或向后走 n 步。确认当前朝向和步数。
turnLeft()
turnRight()		向左转、向右转。转向后角色朝哪边？
attack()攻击相邻目标，可砍树或顶石头；按附件描述会检查前后左右目标。先确认目标是否在可攻击范围。
repeat(n)重复执行其缩进代码 n 次。循环次数、缩进层级。
press()按下开关。角色是否已经到达开关处。
goto(target)走向某个对象。目标名称和路线情况。
dTo(target)测量水平或垂直方向的距离；不在同一水平线或垂直线上时不能测量。先判断对象是否在同一行或同一列。
for x in items:按顺序遍历序列元素，也可遍历字符串和字典。每轮 x 代表当前元素。
if / else条件成立执行 if 缩进块，否则执行 else 缩进块。条件、冒号、两块缩进。
prop、stone.big、not附件提到读取目标属性、判断石头大小和否定条件。对象名、属性名和平台实际语法以测试关卡为准。
小心：附件里部分命令说明较简略（例如 prop 和对象属性的具体写法）。不要凭空猜语法，先看老师演示或平台测试关卡。

路线推演：走到宝箱

教学地图：小萝卜从左下角出发，向右走两格，再向上走两格到宝箱。点击按钮逐步执行，看看每一步位置如何改变。

准备出发：起点在左下角，宝箱在右上方。
move(1) # 向右移动一格（示意） move(1) turnLeft() # 转向上方（方向以平台初始朝向为准） move(1) move(1)

这里的网格只演示“动作按顺序执行”的思路；实际比赛地图和初始朝向可能不同。应以题面为准。

模块二：字符串、列表与字典

目标：熟悉高年级组知识范围里的字符串、列表切片和字典操作，为选择题与综合练习做准备。

字符串：切片和常用方法

word = "treasure" print(word[0]) # 第一个字符：t print(word[1:4]) # 下标 1 到 3：rea print(word[::-1]) # 倒序：erusaert print("a-b-c".split("-")) # 按短横线拆分

切片左边界包含、右边界不包含；从 0 开始数位置。

列表：切片、增删与排序

items = ["钥匙", "石头", "金币", "地图"] print(items[0:2]) # 取前两项 items.append("宝箱") # 末尾添加一项 items.remove("石头") # 删除指定值 numbers = [4, 1, 3] numbers.sort() # 原列表从小到大排序

考试更重要的是读懂列表、下标和方法的效果，不必背很多冷门方法。

字典：用名字查属性

treasure = {"位置": "右边", "数量": 2} print(treasure["位置"]) # 按键取值 treasure["数量"] = 3 # 更新数量 for key in treasure: print(key, treasure[key]) # 依次查看键和值

把字典想成“标签 → 内容”：键是标签，值是内容。

例题练习：从基础到组合

这组练习来自你提供的备考整理内容并作了教学化改写，附件本身没有发布这些真题。先自己做，再展开答案核对。

练习 1 · 余数

输入一个正整数，输出它除以 5 的余数。

样例：输入 12，输出 2。想一想：输入得到的是文字，如何转成整数？

x = int(input()) # 读入文字并转换成整数 print(x % 5) # % 计算余数
解析：先用 input() 读入，再用 int() 转整数，最后取余并输出。
练习 2 · 列表统计

输入一行空格分隔的身高，输出最大身高与最小身高的差。

样例：输入 168 152 140 179 155，输出 39。请先用熟悉的写法完成，再考虑是否能简化。

heights = list(map(int, input().split())) print(max(heights) - min(heights))
解析：split() 按空格拆开，map(int, ...) 把每项转成整数，max() 和 min() 求最大最小值。
练习 3 · 字符串遍历

输入一个字符串，把每个字符重复一次后连起来输出。

样例：输入 abc，输出 aabbcc。

s = input().strip() result = "" for ch in s: result += ch * 2 print(result)
解析：循环依次取出字符 ch，把它重复两次并加到结果字符串中。这里特意用基础循环，便于看懂；先掌握思路，再学更简洁的写法。
练习 4 · 游戏条件

角色前方是小石头时攻击；否则向前走一步。

用规则里的 if/else、石头属性和动作命令表达思路。先指出条件，再判断两个分支各执行什么。

思路：检查题目指定对象的大小属性；若为小石头就攻击，否则移动。

if stone.big == False: attack() else: move(1)

注意：这只是依据规则文字写的示意代码。stone 是否代表当前目标、属性比较的具体语法，都要以平台实际示例为准；可以用 not stone.big 表达否定，但也应先确认平台支持的写法。

关于“简洁”：不需要把代码硬挤成一行。先保证关卡目标正确、用了要求的知识点，再删掉重复或多余动作；不要为了短而漏条件。
